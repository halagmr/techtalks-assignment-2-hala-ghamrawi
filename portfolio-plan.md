<h1>Portfolio Plan</h1>
<h3>1. Full-Stack Job Application Tracker</h3>
<p>
A web application for managing job applications. Users can create accounts, add applications, update application statuses, and filter applications by company, position, or status. The project uses React, Next.js, TypeScript, Tailwind CSS, Next.js API routes, and PostgreSQL. It includes authentication, CRUD operations, form validation, responsive design, and database management.
</p>

<p><strong>Skills demonstrated:</strong> React, Next.js, TypeScript, Tailwind CSS, APIs, PostgreSQL, authentication, CRUD operations, database management, responsive design, Git and GitHub.</p>

<h3>2. Developer Community Platform (already created but needs improvement)</h3>
<p>
A platform where developers can create profiles, publish posts, ask questions, comment, and explore different topics. Users can create, edit, and delete their own posts and view other developers' profiles. The project uses Next.js, React, TypeScript, PostgreSQL, and APIs, with dynamic routes and authentication.
</p>

<p><strong>Skills demonstrated:</strong> React, Next.js, TypeScript, PostgreSQL, REST APIs, authentication, CRUD operations, database relationships, dynamic routing, reusable components, responsive design, Git and GitHub.</p>

<h3>3. Online Learning Platform</h3>
<p>
A learning platform where users can browse courses, create accounts, enroll in courses, and track their learning progress. Instructors can create and manage courses, while different user roles have different permissions. The application uses Next.js, React, TypeScript, PostgreSQL, and authentication.
</p>

<p><strong>Skills demonstrated:</strong> Next.js, React, TypeScript, PostgreSQL, authentication, authorization, role-based access, APIs, database design, CRUD operations, form handling, responsive design, deployment, and Git.</p>
