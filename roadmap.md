<h1>Six-Month Learning Roadmap</h1>

<body>
<h2>Month 1: HTML, CSS & JavaScript</h2>
    <ul>
        <li>Learn HTML and semantic elements</li>
        <li>Learn CSS, Flexbox and Grid</li>
        <li>Learn responsive design</li>
        <li>Learn JavaScript basics</li>
        <li>Practice Git and GitHub</li>
    </ul>
  <h2>Month 2: Advanced JavaScript & React</h2>
    <ul>
        <li>Learn modern JavaScript</li>
        <li>Learn APIs and async/await</li>
        <li>Learn React components and props</li>
        <li>Learn state and hooks</li>
        <li>Build small React projects</li>
    </ul>
<h2>Month 3: Next.js & TypeScript</h2>
    <ul>
        <li>Learn Next.js</li>
        <li>Learn routing and layouts</li>
        <li>Learn Server and Client Components</li>
        <li>Learn TypeScript basics</li>
        <li>Build a multi-page website</li>
    </ul>
<h2>Month 4: Backend & Databases</h2>
    <ul>
        <li>Learn Node.js</li>
        <li>Learn REST APIs</li>
        <li>Learn SQL</li>
        <li>Learn PostgreSQL</li>
        <li>Build a CRUD application</li>
    </ul>
<h2>Month 5: Full-Stack Development</h2>
    <ul>
        <li>Learn authentication</li>
        <li>Connect frontend to backend</li>
        <li>Learn database relationships</li>
        <li>Learn basic security</li>
        <li>Build a complete full-stack project</li>
    </ul>
<h2>Month 6: Deployment & Portfolio</h2>
    <ul>
        <li>Learn how to deploy applications</li>
        <li>Improve GitHub profile</li>
        <li>Build a personal portfolio</li>

        <li>Prepare for internships and junior developer jobs</li>
